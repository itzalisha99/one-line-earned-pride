## The line

> For three years she practised the same piano piece every morning before work, and today her daughter heard it from the kitchen and stopped washing the dishes to listen.

## How it works

`main.py` (Python standard library only, no dependencies) writes that single
line to `/output/entry.txt`. It is deterministic: every run produces the exact
same line. A `validate()` gate check mirrors the bounty gate (1–240
characters, UTF-8, not only whitespace, one line) before writing.

Run it with:

```sh
python3 main.py
```
